도구 / API 이름 호출 프로토콜 설명 및 주요 매개변수
convert_document MCP Tool REST POST 한글(.hwp, .hwpx), DOCX ➔ 고화질 PDF 무손실 즉시 변환 (file_path)
convert_document_to_word MCP Tool REST POST 한글(.hwp, .hwpx) ➔ 서식 보존 Word (.docx) 변환 (file_path)
batch_convert_folder MCP Tool REST POST 폴더 내 모든 한글 문서를 PDF 또는 Word로 일괄 변환 (input_folder, target_format)
parse_document MCP Tool REST POST 표(Table)와 발표자 노트를 보존하여 구조화 마크다운으로 추출 (file_path)
search_knowledge MCP Tool REST POST ChromaDB + BM25 하이브리드 지식 검색 수행 (query, top_k)
index_document MCP Tool REST POST 문서를 파싱하여 지식 베이스에 자동 인덱싱 (file_path, category)
get_system_status MCP Tool REST GET 허브 가동 상태 및 전체 등록 문서 통계 조회
