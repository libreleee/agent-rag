# 📑 02. PDF 문서 파싱, 표 추출 및 지식 임베딩 가이드

본 문서는 사내 공시자료, 학술 논문, 기술 매뉴얼 등 표준 PDF 문서를 **AI Agentic Knowledge Hub**에 고품질로 인덱싱하기 위한 기술 가이드입니다.

---

## 1. PDF 문서의 주요 과제

1. **2단/다단(Multi-column) 레이아웃**: 단순 텍스트 추출 시 좌우 컬럼이 한 줄로 뒤섞이는 현상(Reading Order 파괴) 발생
2. **표(Table)와 텍스트 혼재**: 표의 경계선이 없는 경우 데이터 열이 분리되지 않고 하나의 긴 문장으로 왜곡됨
3. **스캔본(Scanned PDF)**: 텍스트 레이어가 없는 이미지 기반 PDF의 경우 OCR(광학 문자 인식) 파이프라인 필수

---

## 2. 사용 도구 및 엔진

* **PyMuPDF (`pymupdf` / `fitz`)**: 초고속 텍스트 블록 추출, 단락 바운딩 박스(Bounding Box) 좌표 기반 정렬
* **PDFplumber**: 선(Line) 및 직사각형(Rect) 기반 표 영역 검출 및 Markdown Table 복원
* **Surya / PaddleOCR (확장 옵션)**: 이미지 스캔 PDF 발생 시 백엔드 OCR 연동

---

## 3. 구조 보존 파싱 전략

```
 [ PDF 원본 페이지 ]
  ┌───────────────┐
  │ [헤더/제목]   │  ➔ 페이지 상단 블록을 H1/H2로 식별
  │ ┌────┐ ┌────┐ │
  │ │1단 │ │2단 │ │  ➔ X좌표(좌측 ➔ 우측), Y좌표(상단 ➔ 하단) 순 정렬하여
  │ └────┘ └────┘ │     다단 읽기 순서 완벽 복원
  │ ┌───────────┐ │
  │ │ 표(Table) │ │  ➔ 격자 좌표 분석 ➔ Markdown Table 문법으로 치환
  │ └───────────┘ │
  └───────────────┘
```

### 메타데이터 설계
```json
{
  "source": "2026_AI_기술동향보고서.pdf",
  "file_type": "pdf",
  "page_number": 12,
  "total_pages": 45,
  "has_tables": true,
  "chunk_id": "pdf_012_chunk_1"
}
```

## 4. Hub 등록 및 활용

* **웹 UI (`localhost:8001`)**: `[RAG 지식 문서 등록]` 탭에서 PDF 드롭 ➔ 페이지별 구조화 마크다운 파싱 ➔ ChromaDB 저장
* **에이전트 검색 질의 예시**:
  > *"기술동향보고서 12페이지에 나온 2026년 LLM 시장 전망 표 내용 알려줘."*  
  > ➔ HybridRetriever가 `page_number: 12`와 표 마크다운 청크를 정밀 추출하여 응답.
