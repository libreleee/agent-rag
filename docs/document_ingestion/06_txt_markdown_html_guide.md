# 🌐 06. 텍스트, 마크다운, 웹페이지 (TXT / MD / HTML) 파싱 가이드

본 문서는 일반 텍스트, 개발 문서/위키(Markdown), 사내 웹페이지 및 공지사항(HTML)을 **AI Agentic Knowledge Hub**에 고품질로 인덱싱하기 위한 기술 가이드입니다.

---

## 1. 주요 특징 및 정제 과제

* **HTML/웹페이지**: 네비게이션 바, 푸터(저작권), 배너 광고, 자바스크립트 등 노이즈 제거 필수
* **Markdown**: `#` 헤딩 계층, 코드 블록(````python ... ````), 인라인 링크를 보존하여 정밀 청킹
* **일반 텍스트 (TXT)**: 줄바꿈 문맥 유지 및 빈 줄/구분선 정제

---

## 2. 사용 도구

* **`trafilatura`**: 웹페이지 본문 자동 판별 및 보일러플레이트(광고/메뉴) 95% 이상 제거
* **`BeautifulSoup4` + `lxml`**: 정형화된 사내 위키/인트라넷 HTML 태그 정밀 추출
* **`markdown` / `markdown-it-py`**: 마크다운 AST 기반 헤딩/코드블록 정밀 슬라이싱

---

## 3. 정제 및 청킹 파이프라인

```
 [ 원본 HTML / 웹페이지 ]
            │
            ▼ (trafilatura 정제)
 [ 본문만 추출된 순수 마크다운 ]
  # 시스템 설치 가이드
  ## 1. 사전 요구사항
  ```bash
  uv sync
  ```
            │
            ▼ (헤딩 단위 Semantic Chunking)
 [ 지식 청크 생성 & BGE-M3 임베딩 ]
```

---

## 4. Hub 등록 및 활용

* **URL 크롤링 등록**: 웹페이지 URL 입력 시 자동 다운로드 ➔ HTML 파싱 ➔ ChromaDB 저장
* **코드 및 기술문서 검색**: 프로그래밍 코드 블록이 깨지지 않고 온전히 검색 및 에이전트 인용 가능
