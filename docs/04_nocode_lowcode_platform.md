# 04. No-Code / Low-Code 플랫폼 설계

본 아키텍처는 비개발자(기획자, 현업 실무자)도 사내 문서를 지식으로 등록하고, 에이전트 워크플로우를 구성하며, 챗봇을 즉시 배포할 수 있는 **No-Code / Low-Code AI Platform**으로 확장 가능합니다.

---

## 1. 4대 핵심 모듈 및 UI 화면 설계

```
┌────────────────────────────────────────────────────────────────────────┐
│                   No-Code / Low-Code AI Platform                       │
├──────────────────┬───────────────────┬──────────────────┬──────────────┤
│ 1. 지식 스튜디오  │ 2. 워크플로우 캔버스│ 3. 학습 스튜디오  │ 4. 앱 배포   │
│   (KM Studio)    │  (Agent Canvas)   │(Training Studio) │ (App Center) │
├──────────────────┼───────────────────┼──────────────────┼──────────────┤
│ • 파일 드래그앤드롭 │ • 노드 기반 드래그 │ • 원클릭 합성 QA  │ • 웹 위젯    │
│ • HWP/PDF 자동변환│ • RAG 검색 노드    │   데이터 생성    │ • 슬랙/카카오│
│ • 청크/표 시각화 │ • IF/Else 조건분기│ • 데이터 검수/수정│ • API Key    │
│ • 부서별 권한 태깅 │ • 사내 API 도구호출│ • 파인튜닝 트리거│   관리       │
└──────────────────┴───────────────────┴──────────────────┴──────────────┘
```

### 1) 지식 관리 스튜디오 (KM Studio)
* **파일 업로드**: HWP, PPTX, PDF, Word 등을 드래그 앤 드롭으로 업로드.
* **시각적 청크 검수**: 슬라이드별/표 단위로 분할된 텍스트를 미리보기로 확인하고 불필요한 청크 제거 또는 태그 수정.
* **메타데이터 관리**: 문서별 보안 등급, 부서명, 유효기간 등을 GUI로 지정.

### 2) 에이전트 워크플로우 캔버스 (Agent Canvas)
* **React Flow 기반 노드 드래그 앤 드롭**:
  - `[Start 노드]` ➔ `[질의 재작성 노드]` ➔ `[KM 지식 검색 노드]` ➔ `[유사도 점수 분기(IF/ELSE)]`
  - 유사도 >= 0.7 ➔ `[LLM 답변 노드]`
  - 유사도 < 0.7 ➔ `[웹 검색 노드]` or `[담당자 티켓 발행 노드]`
* 코딩 없이 마우스 클릭과 선 연결만으로 실무 프로세스를 자동화.

### 3) 학습 스튜디오 (Training Studio)
* 지식 베이스의 문서를 선택하고 **[합성 QA 생성]**을 클릭.
* 생성된 질문-답변 테이블에서 관리자가 내용을 검토/승인.
* **[LoRA 파인튜닝 실행]** 버튼 클릭 시 백엔드 GPU 서버에서 비동기 학습 시작 및 진행률(Loss Graph) 시각화.

### 4) 앱 센터 (App Center & Deployment)
* 완성된 에이전트를 클릭 한 번으로 배포:
  - **웹 챗봇 위젯**: HTML에 삽입할 `<script>` 코드 제공.
  - **사내 메신저**: Slack, Teams, KakaoTalk 웹훅 연동.
  - **REST API**: 외부 사내 시스템 연동을 위한 API 엔드포인트 및 API Key 생성.

## 2. 기술 스택 및 구현 전략

### 전략 A: 오픈소스 기반 커스텀 플랫폼 확장 (Fast Track)
* **추천 오픈소스**: **Dify** 또는 **Flowise**
* **장점**: UI/UX, 노드 캔버스, 계정/권한 관리가 이미 완성되어 있어 즉시 적용 가능.
* **커스텀 영역**:
  - 한국어 문서(HWP/HWPX) 전용 파서 플러그인 연동
  - BGE-M3 등 한국어 임베딩/Reranker 모델 커스텀 공급자 등록
  - 사내 온프레미스 LLM (vLLM / Ollama) 연동

### 전략 B: 자체 풀스택 플랫폼 구축 (Full Custom)
* **프론트엔드**: Next.js 14 + React Flow (캔버스 UI) + Tailwind CSS
* **백엔드**: FastAPI (Python) + Celery / Redis (비동기 파싱/학습 작업 큐)
* **오케스트레이션**: LangGraph (상태 기반 에이전트 그래프)
* **장점**: 회사의 사내 규정, 레거시 DB, 독자적인 보안 및 보고서 템플릿과 100% 밀착 개발 가능.
